# Security policy

This portfolio deployment supports the current `main` branch. It is not a
managed service or a promise of production SLA. Please report suspected
vulnerabilities privately to the repository owner through GitHub's private
security advisory flow (or the repository owner's verified contact) rather
than opening a public issue. Include a minimal reproduction and impact, but
never include real credentials, API keys, tokens, customer data, or live SOC
telemetry. Redact hostnames and identifiers where possible.

Reports are acknowledged within 5 business days and triaged for severity and
fix scope. Coordinated disclosure timing is agreed with the reporter after
validation. Rotate any secret accidentally disclosed immediately.
